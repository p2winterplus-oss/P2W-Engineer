# วิธีเพิ่ม/แก้ไขบทความ

## วิธีที่ 1 — เผยแพร่ทันทีจาก editor (ง่ายสุด) 🔒
1. เปิด `https://p2winterplus.com/engineer/articles/editor.html`
2. ใส่รหัสผ่าน: **`Chev9872`**
3. **ตั้งค่าครั้งแรกครั้งเดียว**: กด "ตั้งค่าการเชื่อมต่อ GitHub" → วาง GitHub Fine-grained token (สิทธิ์ Contents = Read and write บน repo P2W-Engineer) → บันทึก (เก็บในเครื่องนั้น)
4. กรอกฟอร์ม → กด **"🚀 เผยแพร่ทันที"** → บทความขึ้นเว็บภายใน 1-2 นาที **ไม่ต้อง copy/วาง/push เอง**

> token เก็บใน localStorage ของเครื่องนั้น เข้าครั้งต่อไปไม่ต้องใส่ใหม่ · ถ้าเป็นเครื่องคนอื่นให้กด "ลบ Token" ก่อนออก

## วิธีที่ 2 — สร้างโค้ดแล้ววางเอง (ไม่ต้องมี token)
1-2 เหมือนข้างบน → กรอกฟอร์ม → กด "สร้างโค้ด (วางเอง)" → คัดลอก
3. เปิดไฟล์ `articles/articles.json` วางโค้ดต่อจาก `[` ตัวแรก (คั่นบทความเดิมด้วย `,`)
4. commit + push ขึ้น GitHub

## วิธีที่ 3 — บอกในแชท Claude Code
พิมพ์เนื้อหาบทความมาในแชท ให้ Claude เขียน + push ให้เลย

**การพิมพ์เนื้อหาในช่อง "เนื้อหาบทความ":**
- เว้นบรรทัดว่าง = ขึ้นย่อหน้าใหม่
- ขึ้นต้นบรรทัดด้วย `##` = หัวข้อย่อย
- ขึ้นต้นด้วย `[รูป]URL | คำบรรยาย` = แทรกรูป (คำบรรยายใส่หลัง `|` จะมีหรือไม่มีก็ได้)

## วิธีที่ 2 — แก้ JSON ตรงๆ
แต่ละบทความคือ object 1 อันใน `articles.json`:
```json
{
  "id": "ชื่อ-ภาษาอังกฤษ-ไม่ซ้ำ",
  "title": "หัวข้อบทความ",
  "category": "โซล่าร์เซลล์",
  "date": "2026-09-15",
  "author": "ทีมวิศวกร P2W",
  "cover": "URL รูปปก",
  "excerpt": "เกริ่นนำสั้นๆ",
  "content": [
    { "type": "p", "text": "ย่อหน้า" },
    { "type": "h", "text": "หัวข้อย่อย" },
    { "type": "img", "src": "URL", "caption": "คำบรรยาย" }
  ]
}
```
- `category` ที่ใช้: งานโครงสร้าง / โซล่าร์เซลล์ / ความรู้วิศวกรรม / ข่าวบริษัท
- บทความใหม่สุด (date ล่าสุด) จะขึ้นเป็น "บทความแนะนำ" อัตโนมัติ

กรอกข้อมูลด้านล่าง → กดปุ่ม "สร้างโค้ด" → คัดลอกไปวางในไฟล์ articles.json

ใช้ URL รูปจากอินเทอร์เน็ต หรืออัปโหลดรูปเข้า repo แล้วใส่ path

พิมพ์ได้ตามปกติ · เว้นบรรทัดว่างเพื่อขึ้นย่อหน้าใหม่ · ขึ้นต้นบรรทัดด้วย ## = หัวข้อย่อย · ขึ้นต้นด้วย [รูป] ตามด้วย URL = แทรกรูป

วิธีสร้าง token (ทำครั้งเดียว):
1. ไปที่ github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens
2. Generate → เลือก repo P2W-Engineer → Permissions: Contents = Read and write
3. คัดลอก token มาวางช่องด้านบน → บันทึก

โค้ดที่ได้ — คัดลอกไปวางใน articles.json

วิธีใช้: เปิดไฟล์ articles.json → วางโค้ดนี้ต่อจาก [ ตัวแรก (คั่นบทความเดิมด้วยเครื่องหมาย ,) → บันทึก → commit/push ขึ้น GitHub

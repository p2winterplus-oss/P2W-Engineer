2. ข้อมูลที่เราเก็บ

  • ข้อมูลที่คุณกรอกในแบบฟอร์มขอคำปรึกษา: ชื่อผู้ติดต่อ หมายเลขโทรศัพท์ บริษัทหรือหน่วยงาน Line ID อีเมล ประเภทบริการที่สนใจ รายละเอียดโครงการ และไฟล์รูปภาพหรือแบบแปลนที่คุณแนบมา
  • ข้อมูลที่คุณส่งให้เราทาง Line โทรศัพท์ หรืออีเมล: เช่น ชื่อ ช่องทางติดต่อ รูปถ่ายหน้างาน บิลค่าไฟ และรายละเอียดงาน
  • ข้อมูลการตั้งค่าบนอุปกรณ์ของคุณ: เว็บไซต์บันทึกเฉพาะการเลือกโหมดสว่าง/มืดไว้ในเบราว์เซอร์ของคุณ (localStorage) ข้อมูลนี้ไม่ถูกส่งมาที่เรา

ปัจจุบันเว็บไซต์ไม่ได้ใช้คุกกี้หรือเครื่องมือติดตามเพื่อการโฆษณา หากในอนาคตมีการใช้เครื่องมือวิเคราะห์การเข้าชมเว็บไซต์ เราจะปรับปรุงนโยบายนี้ให้ทราบ

3. วัตถุประสงค์ในการใช้ข้อมูล

  • ติดต่อกลับเพื่อให้คำปรึกษา ประเมินงาน และจัดทำใบเสนอราคาตามที่คุณร้องขอ
  • สำรวจหน้างาน ออกแบบ และให้บริการตามสัญญาจ้าง
  • ติดต่อประสานงานระหว่างดำเนินงานและหลังส่งมอบงาน
  • ปฏิบัติตามกฎหมายที่เกี่ยวข้อง เช่น กฎหมายภาษีและบัญชี

เราประมวลผลข้อมูลโดยอาศัยฐานการดำเนินการตามคำขอของคุณก่อนเข้าทำสัญญาและการปฏิบัติตามสัญญา รวมถึงการปฏิบัติตามกฎหมาย เราไม่ขายข้อมูลของคุณ และไม่ใช้ข้อมูลเพื่อส่งโฆษณาโดยไม่ได้รับความยินยอม

4. การเปิดเผยข้อมูลให้บุคคลอื่น

เราเปิดเผยข้อมูลเท่าที่จำเป็นต่อการให้บริการเท่านั้น ได้แก่

  • ผู้ให้บริการระบบส่งแบบฟอร์ม (Web3Forms) ซึ่งส่งข้อมูลจากแบบฟอร์มมาที่อีเมลของบริษัท และผู้ให้บริการอีเมล
  • ผู้ให้บริการโฮสติ้งและเครือข่ายของเว็บไซต์ (เช่น GitHub และ Cloudflare) ซึ่งอาจบันทึกข้อมูลทางเทคนิคของการเข้าชม เช่น หมายเลข IP ตามการทำงานปกติของระบบ
  • หน่วยงานรัฐหรือการไฟฟ้า เมื่อจำเป็นต้องยื่นเอกสารขออนุญาตในนามของคุณ และได้รับความยินยอมจากคุณแล้ว
  • หน่วยงานที่มีอำนาจตามกฎหมาย เมื่อมีกฎหมายกำหนด

ผู้ให้บริการบางรายอาจจัดเก็บข้อมูลบนเซิร์ฟเวอร์นอกประเทศไทย ซึ่งเป็นไปตามมาตรฐานการคุ้มครองข้อมูลของผู้ให้บริการนั้น

5. ระยะเวลาเก็บข้อมูล

เราเก็บข้อมูลเท่าที่จำเป็นตามวัตถุประสงค์ข้างต้น สำหรับผู้ที่ติดต่อสอบถามแต่ยังไม่ได้ว่าจ้าง เราจะเก็บข้อมูลไม่เกิน 2 ปีนับจากการติดต่อครั้งล่าสุด สำหรับลูกค้าที่ว่าจ้าง เราจะเก็บข้อมูลตลอดระยะเวลาของสัญญาและระยะเวลาที่กฎหมายกำหนด จากนั้นจะลบหรือทำลายข้อมูล

6. สิทธิของคุณ

คุณมีสิทธิตามกฎหมายคุ้มครองข้อมูลส่วนบุคคล ได้แก่ สิทธิขอเข้าถึงและขอรับสำเนาข้อมูล สิทธิขอแก้ไขข้อมูลให้ถูกต้อง สิทธิขอลบหรือทำลายข้อมูล สิทธิขอระงับการใช้ข้อมูล สิทธิคัดค้านการประมวลผล สิทธิขอโอนย้ายข้อมูล และสิทธิถอนความยินยอม (ในกรณีที่ประมวลผลโดยอาศัยความยินยอม)

หากต้องการใช้สิทธิ ติดต่อเราทางอีเมล info@p2winterplus.com หรือโทร. 088-788-8364 เราจะดำเนินการภายใน 30 วันนับจากวันที่ได้รับคำขอ หากคุณเห็นว่าเราไม่ปฏิบัติตามกฎหมาย คุณมีสิทธิร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล (สคส.)
